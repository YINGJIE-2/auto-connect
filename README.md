# auto-connect

> 校园网自动认证 —— 填一次学号密码，以后开机自动联网，掉线自动重连。

[![Go](https://img.shields.io/badge/Go-1.23+-00ADD8?logo=go&logoColor=white)](https://go.dev)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-0078D6?logo=windows)](#)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

每次开机都要打开认证页面、输学号、输密码、选运营商……这个工具就是来解决这件事的。

---

## 特性

| | |
|---|---|
| **开箱即用** | 下载一个 exe，双击，填一次学号密码。**不需要装 Python、不需要装任何运行环境** |
| **开机自动** | 优先注册进任务计划程序（延迟 30 秒、网络就绪才启动、崩溃自动重启）；被安全策略挡住时**自动降级为注册表启动项** |
| **掉线重连** | 每 30 秒探测一次，掉线立刻自动重登 |
| **不占资源** | 单文件约 6 MB，常驻内存约 8 MB，空闲时 CPU 占用为 0 |
| **密码安全** | 用 Windows DPAPI 加密存储，**换电脑、换 Windows 账号都解不开**；配置文件里不存密码 |
| **零第三方依赖** | 纯 Go 标准库实现，`go build` 一次成功 |

## 快速开始

### 1. 下载

到 [Releases](../../releases) 页面下载 `auto-connect.exe`，放到任意目录（比如 `D:\Tools\`）。

### 2. 双击运行

**第一次**双击会先带你配置一遍：

```
  auto-connect · 校园网自动认证
  开箱即用：填一次学号密码，以后开机自动联网、掉线自动重连。
-----------------------------------------------------------
学号: 2506249001
密码（输入时不显示）: ********
再输一次确认: ********

你在认证页第一个下拉框里选的是哪个？
  1) 中国电信
  2) 中国移动
  3) 中国联通
  4) 校园内网
请输入编号 [1]: 2

[1/3] 配置已保存
[2/3] 正在测试认证 ... 认证成功！
[3/3] 注册开机自启 ... 已注册。
```

配完之后每次双击，打开的是**操作菜单**：

```
===========================================================
  账号     : 2506249001@cmcc（中国移动）
  当前状态 : 已联网
  后台守护 : 运行中
  开机自启 : 已开启
-----------------------------------------------------------
  1) 立即检测并重连
  2) 修改配置（学号 / 密码 / 运营商）
  3) 启动后台守护（关掉本窗口也会继续跑）
  4) 停止后台守护
  5) 开机自启  开启 / 关闭
  6) 查看日志
  0) 退出
-----------------------------------------------------------
  提示：已全部就绪，以后开机不用管它。
```

> **这个窗口只是个遥控器，随时可以关掉。**
> 真正干活的是「后台守护」——它是独立进程，关掉菜单窗口不影响它。

配好 + 开了开机自启之后，**日常完全不需要再打开这个程序**。

### 3. 需要时查看状态

直接双击程序看菜单，或者用命令行：

```powershell
auto-connect.exe status
```

## 命令一览

| 命令 | 作用 |
|---|---|
| `auto-connect` | **双击运行**：打开操作菜单（未配置则先走配置向导） |
| `auto-connect setup` | 重新配置（改密码、换运营商） |
| `auto-connect daemon` | 在当前窗口里常驻守护（**关掉窗口就停**，一般用菜单的 3) 代替） |
| `auto-connect daemon --hidden` | 无窗口守护（开机自启用这个） |
| `auto-connect status` | 查看当前联网状态、账号、自启状态 |
| `auto-connect login` | 立刻认证一次（不等守护周期） |
| `auto-connect log` | 显示日志文件路径 |
| `auto-connect install` | 注册开机自启 |
| `auto-connect uninstall` | 取消开机自启（想彻底卸载时用） |

## 常见问题

**Q：提示「账号或密码不对」怎么办？**
先去浏览器手动登录一次确认密码。注意：**密码连续输错会触发图形验证码**，所以本程序在连续失败后会主动降低重试频率（每 5 分钟一次），避免把你的账号刷到弹验证码。

**Q：会不会让我的密码泄露？**
不会。密码用 Windows 的 DPAPI 接口加密，密钥由系统根据你的 Windows 登录凭据派生，**绑定当前机器 + 当前 Windows 账号**。把 `cred.bin` 复制到别的电脑上根本解不开。配置文件和日志里都不含密码。

**Q：为什么不用 ping 判断有没有网？**
因为校园网网关不封 ping。未认证时 `ping www.baidu.com` 照样能通，看不出问题。本程序用的是系统判断「是否需要登录 WiFi」的同一套标准探测方法。

**Q：点「开机自启」时报错怎么办？**
程序有两条通道，会自动切换，菜单里的「开机自启」一行会告诉你实际用的是哪种：

| 显示 | 含义 |
|---|---|
| 已开启（任务计划） | 首选。能延迟启动、等网络就绪、崩溃自动重启 |
| 已开启（注册表启动项） | 降级。任务计划被安全软件/组策略挡住时自动走这条，兼容性更好 |
| 未开启 | 两条都失败了，报错原文会直接显示出来（含系统返回的中文原因） |

如果两条都失败，通常是把程序放在权限受限的目录里 —— 挪到 `D:\Tools\auto-connect\` 这类固定目录再试。

**Q：那个黑色窗口能关掉吗？**
能。它是操作菜单，不是守护进程本体。「后台守护」是菜单启动的独立后台进程，关掉窗口照样跑。你可以在菜单里看到「后台守护：运行中 / 未运行」来确认。

**Q：怎么确认它真的在工作？**
菜单里选 `6) 查看日志`，会显示最近的运行记录；或者去认证页点一次「退出」看看它会不会自动登回来（最多 30 秒）。

**Q：怎么彻底卸载？**
```powershell
auto-connect.exe uninstall
```
然后删掉 exe 文件，以及 `%APPDATA%\auto-connect\` 目录（里面是配置、加密凭证和日志）。

**Q：杀毒软件报警？**
Go 编译的、未做代码签名的 exe 偶尔会被误报。本项目完全开源，你可以自行 `go build` 一份。

## 工作原理

校园网 Portal 认证的本质是：**浏览器向网关提交了一次 HTTP 请求**。我们把这次请求用程序复现出来即可。

```
① 插网线 → DHCP 分配 IP（这一步不需要认证）
        ↓
② 发一个 HTTP 探测请求（captive portal 标准地址）
        ↓
   已认证？ ── 返回 204 ──→ 什么都不做，继续待机
        │
        └─ 被拦截 ──→ 从 302 重定向里解析出动态参数
                ↓
③ 请求网关的认证接口，提交学号 + 密码
        ↓
④ 解析返回 JSON，判断是否成功
```

关键点：
- **只有 http 会被网关劫持**，https 不会 —— 所以探测必须用 http。
- 认证参数（如本机内网 IP）**每次都从 302 重定向里实时解析**，绝不硬编码。
- 认证成功后网关放行有 1~2 秒延迟，**复检必须重试**。

详细协议分析见 [`docs/协议分析.md`](docs/协议分析.md)。

```

├── main.go                      # 操作菜单 + 配置向导 + 命令行入口

└── docs/                        # 协议分析与设计方案
```

## 开发

```bash
git clone https://github.com/YINGJIE-2/auto-connect.git
cd auto-connect
go build -o auto-connect.exe .
```

不依赖任何第三方库，只需要 Go 1.23+。

### 适配其他学校

核心抽象在 `internal/portal/portal.go`：

```go
type Adapter interface {
    Name() string
    Detect(portalBody []byte) bool
    Login(ctx context.Context, env Env) (Result, error)
}
```

新增一个网关只需要：
1. 在 `internal/portal/` 下新建目录，实现上面三个方法；
2. 在 `internal/app/app.go` 的 `adapter()` 里注册；
3. 主流程零改动。

**逆向思路**：多数 Portal 的认证逻辑都写在前端 JS 里（因为要由浏览器提交），把网关首页引用的 JS 读一遍，参数就全暴露了，不需要抓包。参考 [`docs/协议分析.md`](docs/协议分析.md) 里记录的过程。

## 数据与隐私

| 文件 | 内容 |
|---|---|
| `%APPDATA%\auto-connect\config.json` | 学号、运营商、网关参数。**不含密码**，可以安全分享 |
| `%APPDATA%\auto-connect\cred.bin` | DPAPI 加密后的密码。绑定当前机器 + 当前 Windows 账号 |
| `%APPDATA%\auto-connect\auto-connect.log` | 运行日志。**不记录密码** |

本项目不联网上报任何数据。
